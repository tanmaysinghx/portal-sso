2. Adding Applications

Follow these steps to register a new application and connect it to Portal SSO.

1

Open the Console

Log in to the Admin Console and navigate to the OAuth Clients page.

2

Create New Client

Click "New client". Enter your application's name and its redirect URI (the callback URL).

3

Select Client Type

Check the Confidential box if your app runs on a server. Leave it unchecked for Single Page Apps (Angular, React) and Mobile apps.

4

Save & Copy Secret

Click "Create". If you created a Confidential client, you will be shown the client_secret exactly once. Copy it safely!

3. App Integration (OIDC)

Point your OIDC library to the Issuer URL. Portal SSO enforces PKCE for all authorization flows.

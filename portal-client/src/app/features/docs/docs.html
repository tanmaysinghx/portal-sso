Supported CLI Flags

  • --httpPort=8080: Set the HTTP listening port (default: 8080)
  • --httpListenAddress=0.0.0.0: Bind interface address
  • --portalHome=~/.portal-sso: Location for database files, signing keys, and config
  • --prefix=/sso: Context path prefix if running behind a subpath reverse proxy

Database Migration & 1-Click Switch

Start on embedded H2, then seamlessly migrate to production PostgreSQL or MySQL with 1 click.

Portal SSO features a built-in cross-database migration tool under Settings → Database:

  1. Select your target database type (PostgreSQL or MySQL / MariaDB).
  2. Enter your connection parameters or custom JDBC URL and test the connection.
  3. Click "Migrate to Target Database". Liquibase updates the target schema and copies all users, roles, OAuth clients, and keys without downtime.
  4. Click "1-Click Switch & Restart". Portal SSO automatically reloads with the new configuration in under 6 seconds!

Self-registration

Your application links users to this server's sign-up page; it never creates accounts itself. A Portal SSO account grants access to every application behind the server, so no single application decides who exists. Check the policy endpoint before showing a sign-up link — registration is off unless the operator enabled it.

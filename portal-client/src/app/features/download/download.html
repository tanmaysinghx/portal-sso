Installation

@if (activeOs() === 'linux') {

Install on Linux via Terminal

# 1. Download the JAR file
curl -LO http://localhost:8080/api/public/download/portal-sso.jar

# 2. Run with Java 25
java -jar portal-sso.jar --httpPort=8080
} @if (activeOs() === 'mac') {

Install on macOS via Terminal

# 1. Download the JAR file using curl
curl -LO http://localhost:8080/api/public/download/portal-sso.jar

# 2. Start the server (Requires Java 25 installed via Homebrew: brew install openjdk@25)
java -jar portal-sso.jar --httpPort=8080
} @if (activeOs() === 'windows') {

Install on Windows via PowerShell

# 1. Download using PowerShell
Invoke-WebRequest -Uri "http://localhost:8080/api/public/download/portal-sso.jar" -OutFile "portal-sso.jar"

# 2. Run using Java
java -jar portal-sso.jar --httpPort=8080
}

After starting the server, open http://localhost:8080 in your browser to access the admin console and complete the initial setup.

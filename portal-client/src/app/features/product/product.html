Self-hosted OAuth 2.1 & OpenID Connect

Single sign-on for every app you run. One jar. Minutes to set up.

Portal SSO is an identity provider and admin console you host yourself. Run it, add your apps, and give users one sign-in, with PKCE, MFA and audit logging switched on from the start.

Quick setup

From download to first sign-in in three steps.

No containers, no external database, no default passwords to change.

  1. 1

    Run it

    Java 25 is the only requirement. The first run creates the database and prints a one-time admin password.

    java -jar portal-sso.jar
  2. 2

    Add your app

    Applications → New application. Enter a name and URL; the OAuth client, redirect URIs and keys are created for you.

    Keys & setup → Copy .env
  3. 3

    Sign users in

    Install the SDK and call loginWithPopup(), use any OIDC library, or hand the generated guide to your coding agent.

    npm i @tanmaysinghx/portal-sso
New · Connect with Portal SSO

Quick setup with Eggless Observability.

Eggless Observability (logs, live tail and alerts) is the first app built on Connect. It registers itself with your Portal and receives its credentials directly, so nobody pastes a client secret into a config file. Any app can use the same flow.

  • An admin reviews and approves every connection
  • Credentials are bound to the app’s address with a one-time code and verifier
  • Reconnecting rotates credentials instead of creating duplicates
Read the documentation →
  1. 1

    Start from Eggless Observability

    Choose Connect with Portal SSO and enter your Portal’s address. Eggless submits a request describing itself.

  2. 2

    Approve it in Portal

    You land on a review page showing the app, its address and what it asks for. Choose what to allow, then approve.

    EO

    Eggless Observability

    https://eggless.example.com

    Approve
  3. 3

    Sign in with Portal

    Eggless redeems its credentials once, straight to its backend. Your users sign in with their Portal account, MFA included.

01 • Standards & Security

OAuth 2.1 & OIDC Engine

Portal SSO removes deprecated implicit and password grants. It strictly requires PKCE code verification on all relying applications, issues signed JWTs with database-persisted RSA keypairs, and exposes OpenID Connect discovery.

RFC 7636 • RFC 6749 Read Spec →
02 • Identity Governance

Unified Admin & Launchpad

Manage OAuth clients, directory users, roles, and applications. Standard users get a clean single-sign-on launchpad to jump into authorized apps, and can request access directly from administrators with automated role grants.

Zero-Downtime DB Migration

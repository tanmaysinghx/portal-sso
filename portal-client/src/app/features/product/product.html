Identity & Access Management, simplified.

Portal SSO is an open-source OAuth 2.1 and OpenID Connect identity provider. Deploy as a single Java executable with an embedded database, or scale with PostgreSQL. Built for simplicity and speed.

Download & Install

Run Portal SSO anywhere Java 25 is installed. No complex containers required.

Standalone Executable (.jar)

The standard distribution. Contains the backend server, embedded database, and compiled admin dashboard.

Quick Start

java -jar portal-sso.jar --httpPort=8080

This will start the server on port 8080 using the embedded H2 database. An admin password will be generated and printed to the console on first boot.

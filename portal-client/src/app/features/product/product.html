Built for modern stacks

Everything you need in one binary

Standard OIDC & OAuth 2.1

Strictly enforces PKCE for all clients. Completely passwordless-ready with robust crypto including persistent RSA keypairs and BCrypt.

Zero-Friction Boot

A single Spring Boot JAR embeds the compiled Angular SPA. Boots with an embedded H2 database instantly—no external containers required.

Seamless Migrations

Automated migration wizard allows zero-data-loss transfer from the embedded H2 directly into PostgreSQL or MySQL when you're ready to scale.

OIDC Protocol Endpoints

Standard REST endpoints for integrating your client applications. Portal SSO implements the complete OpenID Connect Core specification.
